# Criando seu primeiro schema

- **Arquivo:** `mysql-primeiro-schema` (`.mp4`, `.webp`, `.vtt`)
- **Duração:** 2:11 · 280 palavras de narração (ritmo calmo, com pausas pra tela respirar)
- **Tópico do guia:** `/guia/mysql`
- **Objetivo:** O aluno sabe o que é um schema, entende o prefixo, cria o primeiro pelo painel e encontra ele na lista e no console.
- **Antes de gravar:** Conta de aluno sem nenhum schema, no /dashboard. Esconda o e-mail pessoal se aparecer no topo.

| Tempo | Na tela (o que gravar) | Narração |
|---|---|---|
| 0:03–0:20 | Painel (/dashboard) com "Você ainda não criou nenhum schema." | Antes de criar qualquer tabela, você precisa de um schema. Pense nele como uma pasta: dentro dela ficam as tabelas de um projeto. Aqui no painel dá pra ver que ainda não tem nenhum: a lista Meus schemas está vazia. |
| 0:20–0:42 | Cursor no card "Criar novo schema". Destaque o prefixo antes do campo. | Pra criar o primeiro, use o card Criar novo schema. Repare nesse começo do nome, que já vem preenchido. Esse é o seu prefixo, feito a partir do seu usuário. Como o laboratório é usado pela turma toda, o prefixo garante que o seu schema nunca vai ter o mesmo nome que o de outra pessoa. |
| 0:42–1:02 | Digite "minha escola", destaque a dica "Sem espaços", apague e digite "escola". | Agora escolha um nome curto, que lembre o projeto. Use só letras, números e o sublinhado. Espaço não pode, como avisa a dica logo abaixo do campo. Então, no lugar de minha escola, separado, vou usar só escola. |
| 1:02–1:18 | Clique em "Criar schema". Mostre o aviso de sucesso e o schema em "Meus schemas". | Clique em Criar schema. Pronto! Apareceu o aviso de sucesso, e o schema já está na lista Meus schemas, com o nome completo: o seu prefixo, dois sublinhados, e o nome que você escolheu. |
| 1:18–1:37 | Role até o Console SQL e destaque o seletor "Schema" com o schema novo. | Ele também já aparece aqui embaixo, escolhido no campo Schema do console SQL. O console é onde você vai escrever os comandos: criar tabelas, colocar dados e fazer consultas. A gente vê o console com calma no próximo vídeo. |
| 1:37–1:57 | Abra /guia/mysql, mostre "Dados de exemplo — loja" e clique em "▶ Testar no console". | Uma dica pra estudar: no guia de MySQL, os exemplos têm o botão Testar no console. Clicando nele, o código vai direto pro console, pronto pra rodar no schema que você acabou de criar. Assim você aprende fazendo, sem copiar e colar nada. |
| 1:57–2:11 | Console com o exemplo carregado e o schema escolhido. | Resumindo: o schema é a pasta das suas tabelas, o nome dele leva o seu prefixo, e é nele que os comandos do console vão rodar. Agora é só começar! |

> A legenda `legendas/mysql-primeiro-schema.vtt` sai da coluna Narração com os tempos medidos na gravação gerada (`gerar-videos/`, que escreve `tempos.json`).
