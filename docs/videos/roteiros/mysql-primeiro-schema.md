# Criando seu primeiro schema

- **Arquivo:** `mysql-primeiro-schema` (`.mp4`, `.webp`, `.vtt`)
- **Duração alvo:** 1:30 · 122 palavras de narração (ritmo calmo, com pausas pra tela respirar)
- **Tópico do guia:** `/guia/mysql`
- **Objetivo:** O aluno sabe o que é um schema, cria o primeiro pelo painel e encontra ele na lista.
- **Antes de gravar:** Conta de aluno sem nenhum schema, no /dashboard. Esconda o e-mail pessoal se aparecer no topo.

| Tempo | Na tela (o que gravar) | Narração |
|---|---|---|
| 0:00–0:10 | Painel (/dashboard) com "Você ainda não criou nenhum schema." | Pra guardar tabelas você precisa de um schema. Pense nele como uma pasta onde ficam as tabelas de um projeto. |
| 0:10–0:26 | Cursor no card "Criar novo schema". Destaque o prefixo antes do campo. | No painel, use o card Criar novo schema. Esse começo do nome é o seu prefixo: ele evita conflito com schemas de outras pessoas do laboratório. |
| 0:26–0:42 | Digite "escola" no campo "Nome do schema". Tente digitar com espaço e mostre a mensagem. | Escolha um nome curto, só com letras, números e sublinhado. Espaço não vale. Vou usar escola. |
| 0:42–0:56 | Clique em "Criar schema". O schema aparece em "Meus schemas". | Clique em Criar schema. Pronto: ele já aparece em Meus schemas. |
| 0:56–1:14 | Mostre o seletor "Schema" do Console SQL com o schema novo selecionado. | E já pode ser escolhido no console SQL, logo abaixo. É lá que você vai criar as tabelas e consultar os dados. |
| 1:14–1:30 | Volte ao guia de MySQL, mostre o bloco "Prepare os dados de exemplo" e o botão "▶ Testar no console". | Os exemplos do guia têm o botão Testar no console. Ele leva o código direto pro console, pronto pra rodar no schema que você acabou de criar. |

> A legenda `legendas/mysql-primeiro-schema.vtt` sai da coluna Narração com estes tempos. Se a gravação ficar mais curta ou mais longa, ajuste os tempos no editor (ou peça pra regenerar).
